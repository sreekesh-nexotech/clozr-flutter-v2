10. Mobile implementation checklist
Build the 7 control types in §1 as reusable components before wiring modules.
Search & Select is mandatory wherever listed (users, companies, products) — never a plain checkbox list; these fields can exceed 1,000 entries.
Implement the is / is not toggle on every control marked with it — 11 fields depend on it.
Date filters must offer both quick chips and a From/To calendar; expose only each module’s listed chips.
Respect unit scaling: ₹ lakhs (×100,000) everywhere except Products → Unit price (×1).
Pull admin-configurable option lists (lead sources, stages, customer statuses, task types, product categories) from settings — do not hard-code.
Preserve draft-then-apply semantics, the active-filter count badge, Reset All, and Saved views.
